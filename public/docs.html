How Josked works

Josked tells you whether your email or password showed up in a known data breach, and which services leaked it. It is a static site: no account, no database and no server of our own.

Version 0.1.0

What Josked checks

Email

Lists every breach and paste the address appears in, with the risk level, the data that leaked, and the year.

Password

Counts how often the password appears in breach data. It never gets sent in full.

Breach gallery

Browses the whole database with search, filters and a detail card for each breach.

How it works

Each check is one request made directly from your browser to XposedOrNot, the free breach-lookup service. Josked does not sit in the middle.

  1. Email. The address is trimmed and lowercased, then sent in a query string to api.xposedornot.com/v1/breach-analytics. The answer includes breach details, risk and paste counts.
  2. Password. The password is hashed with Keccak-512 in your browser. Only the first 10 hex characters of that hash go to passwords.xposedornot.com/api/v1/pass/anon/. The answer is a count of breaches whose hashes start with that prefix, and nothing about the password itself.
  3. Reports. Markdown and PDF are built in your browser from the same result. Nothing is uploaded.
  4. Gallery. The full breach list comes from api.xposedornot.com/v1/breaches. It is cached for 15 minutes in sessionStorage, which is per tab.

The password endpoint matches a 10-character hash prefix, so a count can include a few passwords that happen to share it. Treat it as a strong signal, not a certificate.

Privacy

  • Passwords stay in the page. They are not sent in full, saved to storage, or logged. They live only in the open page's memory.
  • No Josked server. Josked has no backend, so it keeps no logs and no database. The site host still sees normal web requests, such as the page you loaded.
  • XposedOrNot sees your request. It receives the email or password prefix and your IP address, as with any API call. Read their privacy policy before you use it.
  • Results live in memory. A checked email stays in JavaScript memory for 10 minutes so repeat checks are fast. Closing the tab clears it. Use Check again to ask XposedOrNot for live data.
  • No referrer. The pages set a no-referrer referrer policy, so XposedOrNot does not receive the page address as a referrer.

Only check an address you own or are allowed to check. Looking up other people's addresses can be harmful, and it is not what Josked is for.

Reading results

FieldMeaning
Risk levelThe risk label XposedOrNot returns for the email. Critical or High is shown in red.
Plain-text leaksBreaches where passwords were stored without protection. Change any password you used on those services.
VerifiedXposedOrNot marks this breach as verified.
SensitiveXposedOrNot flags this breach as sensitive. The gallery lets you filter for these.
PastesPublic text dumps that contained the address. They often hold username and password lists, so change the password if you used it.
Strong hashPasswords were stored with a slow hash. Still change a password you reused, because hashes can be cracked.

Limits and rate limits

  • One request about every 1.1 seconds per page, which matches XposedOrNot's free tier of about one request per second.
  • Results are cached in memory for 10 minutes per email or password prefix, so repeat checks cost no requests. Check again always asks for fresh data.
  • The breach list is cached for 15 minutes per tab. The gallery shows when it was updated, and Refresh loads the latest list at once.
  • Quotas are probably per visitor. Each browser calls XposedOrNot directly, so the limits most likely apply per IP address rather than to one shared server.
  • No unlimited promise. XposedOrNot can add hourly or daily caps to its free tier. If you see “limiting requests”, wait a minute and try again.

Run or host it

Josked needs no build step. Its libraries are vendored in public/vendor/, so nothing is installed. Serve the public/ folder with any static host.

Browsers refuse ES modules opened from file://, so double-clicking index.html will not work. Use one of the options below.

Locally

With Node 18 or newer, run npm start from the project folder and open http://localhost:4173. Python also works: python -m http.server 4173 --directory public.

Hosting

Any static host works, such as GitHub Pages, Netlify, Cloudflare Pages or Vercel static. Upload the public/ folder. No environment variables are needed.

Tests

Run npm test for the parsing, rate-limiting and password-prefix tests.

FAQ

Is it free?

Yes. Josked is MIT licensed, and XposedOrNot's free API needs no key.

Does Josked store my email or password?

No. There is no database. Results live in memory and disappear when you close the tab.

Why does the password check send a prefix?

That is k-anonymity. XposedOrNot only sees 10 characters of a hash, so it cannot learn the password. The same idea powers Have I Been Pwned's range API.

Why is my result “not found”?

XposedOrNot only knows the breaches it has collected. A clean result means it is not in their data, not that the account is safe.

Can I check a whole domain?

Not in this version. XposedOrNot's domain lookups need a Plus API key, and a key must stay secret, which a static site cannot do.
